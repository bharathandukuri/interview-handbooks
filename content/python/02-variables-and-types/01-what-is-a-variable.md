A **variable** is a name that points to a value. Think of it as a sticky note with a name on it, stuck onto a piece of data.

```python
age = 20
city = "Pune"
print(age)
print(city)
```

The screen shows:

```text
20
Pune
```

The `=` sign does **not** mean "equal to", like in maths. It means **save**: take the value on the right and give it the name on the left.

After that, you can use the name as many times as you like.

:::tip[Say it out loud]
`age = 20` reads like "age gets 20". The name is always on the left.
:::
