Python is a **programming language**. You use it to give a computer a list of steps to follow. That list is called a **program**.

People like Python because the code is easy to read. It looks a lot like plain English.

```python
print("Hello, world!")
```

This one line tells the computer to show the words `Hello, world!` on the screen.

Python is used to build websites, work with data, build AI tools, make games, and write small helper scripts. That is why it is a popular first language, and why it shows up so often in job interviews.

:::tip[You do not need to be good at maths]
Programming is mostly about breaking a big job into small steps. You will learn it one small step at a time.
:::
