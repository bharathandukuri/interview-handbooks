`print()` shows something on the screen. Put what you want to show inside the brackets.

```python
print("Hello")       # words need quotes
print(42)            # numbers do not
print("I am", 20)    # use commas to show many things
```

The screen shows:

```text
Hello
42
I am 20
```

Words inside quotes are called **text**. Programmers also call text a **string**.

When you use commas, Python puts one space between the items. Each `print()` also starts a new line.

:::tip[Single or double quotes?]
Both work. `'Hello'` and `"Hello"` mean the same thing. Pick one style and keep using it.
:::
